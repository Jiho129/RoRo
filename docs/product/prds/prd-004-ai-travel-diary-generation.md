# 📝 📝 PRD-004 AI Travel Diary Generation

## 1. Overview
AI가 여행 데이터를 기반으로 하루 여행 이야기를 생성한다.
## Input
- Moment
- Photo
- Location
- Schedule
- User Note
## Output
Daily Travel Diary
- Title
- Summary
- Highlight Moments
- Recommended Photos
- Emotion Description
## AI Principle
AI Draft → User Review → Final Memory
## MVP Acceptance Criteria
✅ 하루 단위 Diary 생성
