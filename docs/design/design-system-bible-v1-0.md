# RoRo Design System Bible v1.0
## Document Purpose
RoRo UI/UX의 시각 언어와 Component 기준을 정의한다.
Figma High Fidelity와 Front-end 구현의 Single Source 기준 문서이다.
---
# 1. Design Philosophy
RoRo의 디자인은 기술을 보여주는 것이 아니라 기억을 경험하게 하는 인터페이스를 만든다.
Core Direction:
Calm Premium
Warm Minimal
Emotional Technology
---
# 2. Design Principles
## Principle 01
Memory First
사진과 순간이 화면의 주인공이다.
## Principle 02
Less UI, More Experience
불필요한 기능 표현을 줄인다.
## Principle 03
Human + AI Balance
AI는 전면에 드러나지 않고 자연스럽게 도움을 준다.

# 6. Core Components
## Moment Card
Purpose:
Represent a travel memory unit.
Components:
- Photo
- Location
- Date
- Story Preview
---
## Timeline Component
Purpose:
Display travel flow naturally.
Components:
- Time
- Place
- Moment
---
## AI Assistant Component
Purpose:
Show AI collaboration.
Rule:
AI suggestion must always be editable.
---
# 7. Motion Principle
Motion should feel like remembering.
Direction:
- Smooth
- Natural
- Minimal
Avoid:
- Game-like animation
- Excessive effects
---
# 8. Figma Implementation Rule
Every component requires:
- Component name
- Variant
- State
- Interaction
- Developer specification
