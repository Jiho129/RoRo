# RoRo Brand Book v1.0
## Document Purpose
RoRo 브랜드의 정체성, 언어, 시각 방향성을 정의하여 UX Design과 Product Experience의 기준으로 사용한다.
---
# 1. Brand Definition
## Brand Name
RoRo
## Category
AI Travel Memory OS
## One Sentence
RoRo는 여행 중 흩어진 순간을 연결하여 다시 경험 가능한 기억으로 만드는 서비스이다.
---
# 2. Naming Philosophy
RoRo는 Roaming에서 출발한다.
여행은 목적지를 빠르게 소비하는 것이 아니라, 천천히 돌아다니며 발견하는 과정이다.
RoRo는 이러한 '방랑하며 발견하는 경험'과 '반복해서 다시 떠올리는 경험'을 의미한다.
Core Meaning:
Roam + Remember + Repeat
---
# 3. Brand Vision
## Vision
Every journey deserves a story that lasts.
모든 여행은 시간이 지나도 다시 꺼내 볼 가치가 있다.
---
# 4. Brand Positioning
## We are NOT
- 여행 SNS
- 사진 저장소
- 일정 관리 앱
## We ARE
- 개인 여행 기억 OS
- 가족 경험 Archive
- AI Memory Companion
---

# Brand Decision
RoRo는 여행을 공유하기 위한 플랫폼이 아니라, 여행을 기억하기 위한 개인 경험 플랫폼이다.
