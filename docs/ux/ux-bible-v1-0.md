# 📘 UX Bible v1.0

## 1. UX Philosophy
RoRo는 여행 기록 앱이 아니라 여행 경험을 다시 살아나게 만드는 Travel OS이다.
## UX Principles
1. 입력보다 자동화
2. 기록보다 Moment 중심
3. AI는 초안을 만들고 사용자가 승인
4. 여행 중 최소 행동
5. 가족 중심 경험
6. 공유는 선택
---
## 2. MVP UX Goal
목표:
LA 가족여행에서 실제 사용 가능한 수준의 여행 기록 경험 제공
핵심 성공 기준:
- 10초 이내 Moment 생성
- AI Diary 초안 생성
- 여행 종료 후 자동 Summary 제공
---

## 5. MVP User Journey
여행 생성 → 일정 등록 → Moment 기록 → AI 분석 → 사용자 승인 → Daily Diary 생성 → Trip Summary
---
## 6. UX Rules
- Auto Save 기본
- AI 결과 수정 가능
- 사진 선택 기반 업로드
- 삭제 전 확인
- 실패 상황에서도 데이터 보존
