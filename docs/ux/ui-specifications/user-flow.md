# 📌 📌 User Flow

## Goal
Define the end-to-end user journey from trip creation to memory completion.
## Main Flow
1. Create Trip
2. Add Moments
3. Upload Photos
4. AI Processing
5. Review AI Diary
6. Generate Highlight Video
7. Share / Archive
## MVP Primary Journey
Trip → Moment → Photo → AI Diary → Memory
## UX Principle
Minimize user input and maximize automatic memory creation.
