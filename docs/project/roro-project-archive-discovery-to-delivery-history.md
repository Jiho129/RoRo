# 📦 RoRo Project Archive - Discovery to Delivery History

## Purpose
RoRo 프로젝트의 초기 아이디어 발굴부터 Product Delivery Sprint 6까지의 의사결정과 산출물 기준을 보존한다.
## 1. Project Vision
- AI Travel Memory OS
- 여행 중 생성되는 경험(Experience)을 Moment 단위로 기록
- AI가 Memory → Story → Archive로 발전시키는 개인 여행 기록 플랫폼
## 2. Brand Direction
- Brand: RoRo
- Meaning: Roam + Remember + Repeat
- Direction: Calm Premium + Warm Minimal + Emotional Technology
## 3. Core Experience Model
Experience → Moment → Memory → Story → Archive
Moment 구성요소:
- Photo
- Location
- Time
- People
- Emotion
- Activity
- User Note
- AI Interpretation
## 4. MVP Scope
Target: Family Travel
Core Features:
- 여행 일정 관리
- 사진 업로드
- AI 여행 일지 초안 생성
- 사용자 승인 후 편집
- 비용 기록
- 공유 권한 관리
- AI Highlight Video 생성

- Notion: Master Source
- Figma: Design Source
