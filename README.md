# 🌍 RoRo

> **Capture the Journey. Relive the Moments.**

RoRo is an AI-powered travel companion that transforms travel moments into meaningful memories.

Instead of spending time writing travel journals, users simply travel, take photos, and save receipts. RoRo automatically organizes moments, generates daily travel diaries, summarizes expenses, and creates highlight videos.

---

# Vision

RoRo helps people remember their journey instead of managing it.

We believe traveling should be experienced first and documented naturally afterwards.

---

# MVP Goal

Deliver a production-ready MVP that can be used during a real family trip to Los Angeles and San Diego.

Target Release

- MVP : July 2026
- Beta : August 2026
